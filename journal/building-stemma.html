Building Stemma without hiding the uncertainty

The interesting question is not whether the software can produce an answer. It is whether the answer deserves to change a scientific decision.

Scientific software can become persuasive long before it becomes scientifically useful. A polished interface or complicated architecture can look mature while the biological question remains unresolved.

Traceability before confidence.

A conclusion should carry the context that produced it: the evidence used, the assumptions made and the conditions under which the system decided it did not know enough.

The project should continue because the biology survives the test — not because the software took a long time to build.

Negative results belong in the history.

If a simpler baseline beats Stemma, that result should determine what happens next rather than being quietly tuned away.
