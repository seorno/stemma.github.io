A marker is not an identity.

Markers are useful shortcuts. The mistake is letting the shortcut become the whole biological argument.

Stemma · October 2026 · 5 min read

Single-cell analysis depends on markers because we need practical ways to interpret high-dimensional expression profiles. But a familiar marker can become too persuasive. A cell expressing one expected gene is not automatically equivalent to the biological state that gene is associated with.

Identity is a program, not a password.

A robust state usually involves coordinated expression, suppression of alternatives, the correct developmental or experimental context, and evidence that the program behaves consistently beyond one snapshot.

That does not make marker genes unhelpful. It means they should be treated as evidence within a wider argument rather than as a binary access code to an identity.

Markers help name a state. They should not be allowed to define the state alone.

Context changes interpretation.

The same gene may appear in related states, stress responses or partial transitions. A convincing claim therefore needs to survive comparison against plausible alternatives and independent contexts.

This is one reason Stemma is built around evidence comparison rather than a single classification output. The difficult part is often not producing a label. It is deciding whether the label deserves to be trusted.
