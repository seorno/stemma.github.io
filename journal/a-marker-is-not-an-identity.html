A marker is not an identity

Markers are useful shortcuts. The mistake is letting the shortcut become the whole biological argument.

Single-cell analysis depends on markers because we need practical ways to interpret high-dimensional expression profiles. But a familiar marker can become too persuasive.

Identity is a program, not a password.

A robust state usually involves coordinated expression, suppression of alternatives and the correct developmental or experimental context.

Markers help name a state. They should not be allowed to define the state alone.

Context changes interpretation.

The same gene can appear in related states, stress responses or partial transitions. The question is whether the broader biological program supports the proposed identity.
