# Stemma commercial website — Ontosma × Granola direction

Static site suitable for GitHub Pages. Publish the contents of this folder from the repository root.

## Visual direction
This revision combines two references without copying either:
- **Ontosma:** editorial/scientific character, serif typography, research-minded writing.
- **Granola:** calm product surfaces, friendly rounded UI, energetic accent colour, oversized type, subtle imperfection and motion.

The result deliberately avoids generic "AI startup" aesthetics. There are no glowing neural networks, chatbot-first framing, fake model scores, or architecture diagrams.

## Included
- `index.html` — commercial homepage
- `journal.html` — filterable Journal landing page
- `journal/*.html` — four starter essays / notes
- `assets/style.css` — shared responsive styling
- `assets/site.js` — navigation, scroll reveals, product tabs, light parallax and Journal filtering

## Animation
- floating evidence cards in the hero
- slow rotating scientific orbit
- mouse parallax on the product workspace
- scrolling evidence ticker
- scroll-triggered reveals
- drifting marker labels
- animated hover states
- reduced-motion accessibility support

## Positioning guardrails
The site sells Stemma's decision value rather than proprietary internals:
- compare transcriptomic evidence across studies
- surface support, contradiction and unknowns
- interrogate state / lineage interpretations
- preserve context and uncertainty
- help frame the next validation question

Avoid publishing proprietary architecture, thresholds, algorithm descriptions, unvalidated performance claims, fake customer logos, or unsupported cost/time savings.
