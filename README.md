# Stemma commercial website concept

Open `index.html` in a browser.

## Positioning
- Commercial-facing, not architecture-facing.
- Emphasizes R&D decisions, traceability, evidence comparison and uncertainty.
- Avoids proprietary algorithms, scientific implementation details, internal thresholds and unsupported performance claims.
- All product UI and confidence values shown on the landing page are conceptual/illustrative.

## Before publishing
- Replace `hello@stemma.bio` if needed.
- Add real Privacy / Terms / LinkedIn URLs.
- Only add customer logos, validation metrics, security claims or pharma outcomes once they are factual and defensible.
