# Stemma commercial website — editorial direction

Open `index.html` in a browser or publish it directly with GitHub Pages.

## Design direction
This revision takes visual cues from the user's Ontosma site without copying it directly:
- warm scientific-journal / print aesthetic
- strong serif editorial typography
- monospaced figure labels and section metadata
- hard rules, double borders and paper-like surfaces
- restrained palette and motion
- no glowing gradients, floating blobs or generic SaaS cards

## Commercial positioning
The site sells the research problem Stemma addresses rather than its internal architecture:
- compare transcriptomic evidence across studies
- inspect support, contradiction and unknowns
- interrogate cell-state and lineage claims
- carry traceable reasoning into experimental and R&D decisions

It intentionally avoids:
- proprietary architecture, algorithms or thresholds
- Genesis implementation details
- fake confidence percentages
- chatbot or "AI copilot" framing
- invented customer logos, testimonials or validation claims
- unsupported claims about time or cost savings
