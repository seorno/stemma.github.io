Ask better questions of transcriptomic data.

Stemma is being built to help researchers examine a biological claim, see what supports it, see what challenges it, and know when the evidence is not strong enough to decide.

Example questions

What could you ask Stemma?

These are the kinds of questions the system is being designed around. They are easier to understand than a list of features.

Cell state

“Does this cluster really support a primitive endoderm identity?”

Inspect the evidence behind a state call instead of accepting the label as the conclusion.

Competing evidence

“Which genes support this interpretation, and which ones argue against it?”

Keep positive, contradictory and missing evidence separate.

Across studies

“Do independent datasets tell the same biological story?”

Compare evidence while keeping species, stage, condition and assay context attached.

Uncertainty

“Is this claim unsupported, contradicted, or simply not testable with the current evidence?”

Distinguish a real negative result from a question the data cannot answer.

Next experiment

“What evidence would reduce the biggest uncertainty in this claim?”

Use the evidence structure to frame a more useful validation question.

Research direction

“Given a starting state and a target phenotype, which interventions are worth testing next?”

This is a longer-term Stemma research direction and is not yet validated for broad prospective prediction.

How it works

A simple workflow.

1

Start with a biological claim.

A proposed state, lineage, comparison or experimental question.

2

Keep evidence and context attached.

Stemma is designed to preserve where the evidence came from, what assumptions were used and where datasets are not comparable.

3

Return something inspectable.

Support, challenge, unknowns and provenance remain visible so the conclusion can be reviewed rather than blindly trusted.

What you get

Not just a score.

A useful biological answer should make it possible to understand why the system reached it.

ConclusionWhat the current evidence supports.
Counter-evidenceWhat challenges the proposed interpretation.
UnknownsWhat cannot yet be judged.
ContextSpecies, state, stage, condition and source remain attached.
ProvenanceInputs, references and assumptions remain traceable.
Validation

We are testing whether Stemma deserves to exist.

The software is already reproducible and auditable. The important question now is whether the biological decisions are actually useful compared with simpler approaches.
